## B. 引き継がなかったもの（必要なら足します）

- **計測タグ**（旧サイトの SiTest）。外部スクリプトを増やさないため入れていません。GA4 などを入れる場合は `app/layout.tsx` に追加します
- **Instagram の投稿一覧の埋め込み**（旧サイトの CMS が提供していたもの）。フッターからのリンクだけにしています
- **ギャラリーのページ**（`/gallery.html`）。写真は各ページに配分し、旧 URL は `/cuisine` へ転送しています
- **Search Console の所有権確認タグ**は引き継ぎました（`data/site.ts` → `googleSiteVerification`）

## C. 外部の掲載との食い違い（検索結果に影響します）

サイトの外にも、店舗の情報が載っています。サイトと食い違っていると、Google が正しい情報を判断しにくくなります。

- **Google ビジネスプロフィール**: 住所・電話番号・営業時間がサイトと同じ表記か。予約リンクが切れていないか
- **一休・食べログ**: 席数（7席）、QR決済（可）が旧サイト（6席・不可）と違います。A-3・A-4 が決まったら、違うほうを直してください
- 住所の正しい表記は、サイト全体で次の1つです
  `〒060-0063 北海道札幌市中央区南3条西6丁目1-8 インフィニ桂和22 7F` ／ `011-206-0358`

## D. 写真について

- `assets/source-photos/line-album-2026-10-07/line-26.jpg` は制作会社の画像だったため、使っていません
- `line-01`（野菜）`line-03`（招き猫）は、店の世界観に合わせて未使用です
- `line-04`〜`line-09` はスマートフォンの画面を撮ったもの（黒帯つき）で、写真の部分だけを切り出しています。**解像度が低い**ため小さく使っています。元の写真データがあれば差し替えると、大きく使えます
- 料理の写真には、料理名や魚の名前を付けていません（確認できていないため）。分かれば `data/photos.ts` の alt に足せます

## E. 自動投稿（季節の便り）

- GitHub の Secrets に `ANTHROPIC_API_KEY` を登録するまで、自動投稿は動きません（登録前は、何もせずに終わります）
- **最初の数本は、公開された記事を必ず読んでください**。検査は通っていても、言い回しの癖や、検査で拾えない誤りが残ることがあります。気になる点は `scripts/journal/lib/validate.ts` に規則を足せます
- 題材は 112 本用意しています（`data/journal-topics.ts`）。尽きたら、モデルに題材を1つ提案させて同じ基準で検査してから書きます
