## D. 写真について

- `assets/source-photos/line-album-2026-10-07/line-26.jpg` は制作会社の画像だったため、使っていません
- `line-01`（野菜）`line-03`（招き猫）は、店の世界観に合わせて未使用です
- `line-04`〜`line-09` はスマートフォンの画面を撮ったもの（黒帯つき）で、写真の部分だけを切り出しています。**解像度が低い**（幅 870px）ため、画面の 4 割ほどまでの大きさで使っています。元の写真データがあれば差し替えると、大きく使えます
- **大きく使える写真が足りていません。** 画面の幅いっぱいに出せるのは、幅 1,500px 以上の 13 枚（うち、暗い色調で世界観に合うものは 7 枚ほど）です。同じ写真を複数のページで使っています。握り・店内・手もとの写真を、横位置・縦位置それぞれ数枚ずつ撮り足すと、ページごとの表情をさらに変えられます
- **高精細な画面・とても広い画面では、写真が少し甘く見えます**（2026-10-07 の調査で実測）。幅 1,566px の写真を画面の幅いっぱいに出すと、MacBook などの高精細な画面（幅 1,440px × 2倍密度）では、必要な画素数の半分ほどしかありません。サイト側でできること（切り抜いて拡大される写真に、拡大後の大きさに合った画像を届ける／幅 1,920px を超える画面では写真を 1,920px で止める）は済ませました。これ以上は、元の写真の画素数で決まります。**長辺 3,000px 以上の元データ**があれば、差し替えるだけで鮮明になります（いま十分な大きさ＝幅 2,880px があるのは、ヒーローの店内写真・日本酒の瓶の写真・二皿の料理と日本酒の写真の 3 枚だけ）
- 料理の写真には、料理名や魚の名前を付けていません（確認できていないため）。分かれば `data/photos.ts` の alt に足せます

## E. 季節の便り（自動投稿）

- GitHub の Secrets に `ANTHROPIC_API_KEY` を登録するまで、自動投稿は動きません（登録前は、何もせずに終わります）
- **「この店にしか書けない記事」には、店からの一次情報が要ります。**
  今日の仕入れ、今週の魚、仕込み、シャリ、煮切り、季節ごとのコースの変化。こうした話は、店舗データに事実が無いため、いまは書けません（モデルに作らせることはしていません）。
  店主・女将から聞き取った内容を `data/shop-notes.ts` に入れると、その日の記事がそのメモをもとに書かれます。月に数件でも入ると、便りの中身が大きく変わります。聞き取りの例：
  - 今月、とくに良い魚は何か。どう仕立てているか
  - 昆布〆・煮ツメ・隠し包丁を、どの魚に、なぜ使うのか
  - シャリ（米・酢・温度）で大事にしていること
  - 三食丼を結びにしている理由
  - 季節でコースの何が変わるか
- **最初の数本は、公開された記事を必ず読んでください**。検査は通っていても、言い回しの癖や、検査で拾えない誤りが残ることがあります。気になる点は `scripts/journal/lib/validate.ts` に規則を足せます
- 検査を厳しくしたため、既定のモデル（Haiku）では通らない日が出るかもしれません。通らない日は公開されないだけです。続くようなら、GitHub の Variables で `CLAUDE_MODEL` を上位のモデルに替えてください
- 題材は 112 本用意しています（`data/journal-topics.ts`。A 19／B 58／C 35）。尽きたら、モデルに題材を1つ提案させて同じ基準で検査してから書きます
- 公開済みの 10 本は、すべてサイト公開日（2026-10-07）の日付です。日付は実際の公開日のままにしています（さかのぼった日付は付けていません）

### 旧サイトの側で、直しておきたいこと（2026-10-09 に確認）
